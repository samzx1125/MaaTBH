# MaaTBH

TaskBarHero 自動化輔助（研究用）

</div>

本專案以 [MaaFramework](https://github.com/MaaXYZ/MaaFramework) 為基礎，針對 **TaskBarHero** 桌面端（Win32）進行自動化流程研究與實驗。目前主要實作內容包含合成（裝備 / 材料 / 飾品）等任務 pipeline。

> **MaaFramework** 是基於影像識別技術、運用 [MAA](https://github.com/MaaAssistantArknights/MaaAssistantArknights) 開發經驗去蕪存菁、完全重寫的新一代自動化黑盒測試框架。
